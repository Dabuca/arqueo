# HackMeridian submission pack

This folder holds the source materials for the Arqueo submission. The event reviews a demo video, pitch deck, GitHub repository, and submission answers asynchronously. The exact submission form is behind the event platform sign-in, so `form-answers.md` is an answer bank to map to its live fields rather than a claim that the form has been submitted.

## Materials

- [Pitch deck](pitch-deck.html) — present in a browser; use the left and right arrow keys to navigate.
- [Demo-video script](demo-video-script.md) — a truthful recording plan with the currently documented testnet evidence.
- [Form-answer draft](form-answers.md) — concise responses aligned with the public judging criteria.

## Still required before R10 can be marked complete

1. Record the real app and testnet transactions using the script. Do not show a simulated or placeholder transaction as live evidence.
2. Verify the unknown-supplier rejection on testnet before claiming scene 3.
3. Capture a shareable video link and replace the pending link in the answer draft and pitch deck.
4. Sign in to the HackMeridian submission platform, map the answer draft to its actual fields, provide the team and contact details, and submit before the deadline.
5. Open the public repository, video, and deck links in a private browser window and confirm that judges can access them.

The official event site says judging reviews the demo video, pitch deck, GitHub repository, and submission answers, and sets the deadline to Monday 26 October 2026 at 12:00 Lisbon time: [HackMeridian Build](https://www.hackmeridian.com/build).
