What is new

Who controls the controls?

  • Only the admin can change limits or suppliers, signing with a passkey.
  • The new rule goes live before the old one is removed: never an unguarded second.
  • Changing a limit never resets the 30-day cap, and it cannot drop below what is spent.

For the auditor

Every change is logged: old value, new value and the transaction hashes.

How we detect it

The network keeps the original

1 · Every record keeps its hash

Each payment and each settings change is saved with its Stellar transaction hash.

2 · Stellar holds the truth

That hash points to a transaction sealed in the ledger. Nobody can rewrite it.

3 · Compare, and it shows

The books say 2,000, Stellar says 200. The record is forged, and it is plain to see.

Today: one click per record opens it on stellar.expert. Next: the app re-checks the whole log on its own.

No screenshots, no trust required: the evidence is public and permanent.
